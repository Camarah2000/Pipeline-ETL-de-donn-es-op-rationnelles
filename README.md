# Pipeline-ETL-de-donn-es-op-rationnelles
**Projet personnel — Pipeline ETL de données opérationnelles (PowerShell & SQL)**

- Développement d'une chaîne ETL automatisée avec PowerShell.
- Extraction et traitement de fichiers CSV.
- Nettoyage, normalisation et validation des données.
- Détection et gestion des doublons et anomalies.
- Modélisation et stockage des données dans une base SQL.
- Création de requêtes d'analyse et d'indicateurs métier.
- Conception d'un tableau de bord de visualisation des données.
- Documentation des processus de traitement et de l'architecture du projet.
